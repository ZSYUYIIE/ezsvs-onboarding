# 大堂闸机默认关闭

版本 `0.4.3-web.3`，2026-11-19。

大堂闸机使用关闭的玻璃挡板。三条通道的机身和玻璃均保留碰撞，角色从任意一侧走向挡板时会被挡住。沿用 1.4 米闸机宽度和对齐后的两侧护栏。

第一关通过答题推进。完成本关最后一道题及后续对话后，课程自动切换到第二关。闸机保持关闭。

上一版允许角色走到闸机后方。继续第一关时，若存档位置在关闭挡板附近或后方，角色回到该关的既定大堂入口，答题进度继续保留。

本次恢复模型原有的关闭玻璃，移除上一版为打开玻璃创建的替代网格。机身与玻璃使用独立碰撞体。

30 项专项回归检查已通过，覆盖六处机身、相机碰撞、三条关闭通道的导航阻挡与双向身体阻挡、两侧固定护栏。

普通键盘操作下，角色从 z = −13.5 米走向玻璃，在 z = −12.341 米停止。正常选择最后一道题的正确答案并完成两句后续对话后，进入第二关 `sg1_l2`，存档进度为 stage 2 / step 0。

另用第一关最后一道题、位置在闸机后方的旧存档恢复。角色回到 x = −25、z = −20 的既定入口，stage 1 / step 4 保留，应用错误记录为空。
