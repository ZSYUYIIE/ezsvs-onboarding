# EZSVS · 入职第一天 v0.4.2-web.1

机房性能优化网页版，供电脑、安卓手机和平板浏览器运行。保留中英文、培训进度、证书、分包与浏览器缓存；原版安装包及网页包保留。

## 上传与升级

1. 先在旧网页菜单导出培训存档，并备份原仓库部署文件。
2. 解压 ZIP，将含 index.html 的这一层完整更新到原仓库，保留仓库自己的 .git。
3. Build、StreamingAssets、asset-loader.js、web.js、web.css、locale.js、index.html 使用本包同一版；不要只换首页、不要混用旧 Build。保留 .nojekyll 和 .github/workflows/pages.yml。
4. 提交 main，等待 Actions 的 Deploy EZSVS training to Pages 成功。已有的 GitHub Actions Pages 设置可继续使用。
5. 打开原网址并刷新，确认标题 v0.4.2-web.1，点击“继续上次培训”。保持原域名、仓库路径和浏览器可沿用进度；换设备前先导出、再导入。

本包没有自动部署或上传。首次主要资源约 86.1 MB；人物随楼层准备，分片缓存仍可复用，单片最多 4 MiB。不要改分片名称或手工拼接。

## 手机画质

手机画布密度上限 1.5 倍；文字和按钮使用完整画布。自动档的 3D 场景渲染比例为 75%，流畅档 60%，高清档 90%。网页菜单“画面清晰度”可随时切换，进度与 UI 大小保持不变。较慢设备建议流畅；最高画质需实际确认发热与流畅度。

手机机房重复物体按约 2 米单元合并网格；桌面可使用实例绘制路径。远处机柜使用简化外观，薄线缆限制远距绘制；只用不透明墙体作保守遮挡，门、玻璃和人物碰撞体仍保留。

手机局部灯光最多保留附近 6 盏，单物体最多 2 盏附加灯；主阴影缩短为 10 米硬阴影，局部灯不投影。手机使用环境补光，保留轻量调色与 FXAA，关闭泛光、景深和一次性实时反射探针更新。当前楼层是运行时生成，本轮没有把它描述成已完成离线光照或 Unity 遮挡烘焙。

## 资源释放

离开后销毁旧楼层、释放其生成的网格和材质，卸载当前楼层不需要的人物分包。浏览器的已验证下载缓存继续保留，返回时可以重新载入。常驻 UI 小纹理有独立保护，避免清理资源时按钮背景丢失。

WebAssembly 预留容量、Unity 已用内存和浏览器进程总占用不是同一个量，不能保证任务管理器数字立刻降回 443 MB。本版验证的是当前楼层与人物集合不再累积，以及往返后能正常显示和继续操作。

## 操作与存档

电脑：WASD / 点地行走，右键拖动视角，E 交谈或开门，G 前往目标，H 手册。触屏：左下拖动行走，右侧空白处拖动视角，点人物或交互提示；建议横屏，可从网页菜单全屏。

首页可选中文或 English，网址可附 ?lang=zh / ?lang=en。网页菜单切换语言会先保存再加载，之后点击继续。存档和成绩保存在本机浏览器；没有主管后台或云同步。清除站点数据会失去本机进度，请使用导出存档。

部署包是静态网页，不要双击 HTML；本地预览可运行 python -m http.server 8080，再打开 http://127.0.0.1:8080/。实际使用 Chrome / Edge，避免微信内置浏览器。网页公开访问权限取决于公司的托管安排，本包不含身份验证。
